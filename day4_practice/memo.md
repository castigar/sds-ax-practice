# 최근 트렌드
- mcp 인증이 유지되는 시간 (= 만료 기한)을 아주 짧게 둠 (짧으면 보통 8시간 정도. notion이 이럼.)
- agent 기반 mcp 서버의 부하가 점점 커지는 추세라 그렇고, 유지되는 인증으로 전혀 엉뚱한 걸 요청하거나 하는 등의 일이 있는데
  아무래도 유지보수와 성능 보전 영역이 mcp 서버를 제공하는 벤더사의 커다란 부담으로 작용하기 때문.

# MCP Tool list로 인해 Context Windows가 줄어드는 문제
- 사용자 인증과 권한에 따라 보여주는 도구를 차이나도록 하는 걸로 보통 해결한다.
- docString이 길어지면 Tool 적중률이 높아지지만 또 windows가 줄어드니까 이 부분 역시 구현자가 최적화하면서 휴리스틱하게 접근한다.
